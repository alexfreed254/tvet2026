## Troubleshooting Reference

### Common Issues

**Build Fails:**
- Check logs for specific errors
- Verify environment variables are set
- Confirm dependencies are correct

**Backend Won't Start:**
- Verify `SUPABASE_DB_URL` format
- Check all required env vars are set
- Review Python errors in logs

**Frontend Shows Errors:**
- Confirm `VITE_API_BASE_URL` is correct
- Verify CORS settings
- Check browser console

**Authentication Fails:**
- Verify Supabase redirect URLs
- Check JWT_SECRET is set
- Confirm Supabase keys are correct

## Rollback Plan

If deployment fails:

1. Check service logs for errors
2. Verify environment variables
3. Roll back to previous commit if needed:
   ```bash
   git revert HEAD
   git push origin main
   ```
4. Render will auto-redeploy the previous working version
